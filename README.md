# TracyPrinter
Tracy Printer is a Python project that recreates images using the Turtle graphics library.

The project reads image data and converts it into a format (dependent on the version and method used in past, present, and future) that allows tracy (the turtle) to "print" an image onto the screen.

The name "Tracy" in TracyPrinter is inspired by the common nickname "Tracy" used for the turtle in EDU environments.
